# Support Ticket Classification & Prioritization Using Machine Learning

## 📌 Project Overview

This project focuses on automating customer support operations using Machine Learning and Natural Language Processing (NLP).

The system analyzes customer support tickets, classifies them into different categories, and predicts their priority level. This helps organizations reduce manual effort, improve response times, and manage support requests more efficiently.

---

## 🎯 Objectives

* Automatically classify support tickets into categories.
* Predict ticket priority levels (High, Medium, Low).
* Apply NLP techniques for text preprocessing and feature extraction.
* Evaluate machine learning model performance.
* Generate insights for improving support operations.

---

## 📂 Dataset

Customer Support Ticket Dataset containing:

* Ticket Subject
* Ticket Description
* Ticket Type
* Ticket Priority
* Ticket Status
* Customer Information

The dataset represents real-world customer support scenarios and ticket management workflows.

## 🔄 Project Workflow

### 1. Data Preprocessing

* Combined ticket subject and description.
* Converted text to lowercase.
* Removed punctuation and special characters.
* Removed stopwords using NLTK.

### 2. Feature Extraction

* Applied TF-IDF Vectorization.
* Converted text into numerical features suitable for Machine Learning.

### 3. Machine Learning Models

* Multinomial Naive Bayes
* Logistic Regression

### 4. Model Evaluation

* Accuracy Score
* Classification Report
* Confusion Matrix
